# 04 — Danh mục Dự án (Portfolio)

## Giới thiệu

> "A curated collection of digital experiences blending aesthetic precision with technical rigor."

Danh mục dự án tiêu biểu (Selected Works) thể hiện năng lực thiết kế và kỹ thuật — kết hợp tính thẩm mỹ chính xác với sự nghiêm ngặt kỹ thuật.

---

## Dự án tiêu biểu

### 1. Aether Dynamics
- **Loại**: WebGL Experience
- **Mô tả**: Trải nghiệm tương tác 3D toàn màn hình với hiệu ứng WebGL phức tạp, tối ưu hiệu năng GPU trên mọi thiết bị.

### 2. Nova Interface
- **Loại**: UX/UI System
- **Mô tả**: Hệ thống thiết kế UI/UX đồng bộ — design tokens, component library và interaction patterns nhất quán.

### 3. Chronos
- **Loại**: Motion Identity
- **Mô tả**: Bộ nhận diện thương hiệu chuyển động — animation guidelines, micro-interactions và motion language cho toàn bộ sản phẩm.

### 4. Solaris Engine
- **Loại**: Data Visualization
- **Mô tả**: Hệ thống trực quan hóa dữ liệu tương tác — biểu đồ real-time, dashboard phân tích với hiệu ứng chuyển động mượt mà.

## Đặc điểm chung của mọi dự án

- **Hiệu năng tối ưu**: 60fps trên cả Desktop và Mobile
- **Thiết kế tương tác**: Mọi element đều có phản hồi thị giác (hover, scroll, click)
- **Code chất lượng cao**: TypeScript strict mode, test coverage 100% cho logic nghiệp vụ
- **Responsive**: Hoạt động mượt mà trên mọi kích thước màn hình
